What time zone is the code written in?

Every human commit across all of a project's repositories, placed at the UTC offset its author's own machine recorded. CI runners and release bots are excluded.

How to read this

Concentration thresholds

A common open-source governance rule of thumb: one company below 50% of contribution is balanced; 50–75% is concentrated; at or above 75% the project is effectively single-vendor. The ticks on each gauge mark 50% and 75%.

SAP entities were merged

LFX Insights records SAP, SAP SE, SAP Converged Cloud and SAP Cloud Infrastructure as separate organisations. This page counts them as one company, which raises several projects' top share substantially. Rows where the merge changed the number are marked M — hover to see LFX's raw figure.

Garden Linux is not in LFX Insights

It exists there only as an organisation, not as a tracked project, so it has no LFX health score. Its figures come from the GitHub API and the git history of all 227 repositories in the gardenlinux org, with company attribution derived from commit-author email domains — a coarser method than LFX's affiliation data. Free-mail and noreply addresses can't be attributed to a company and are left out of its percentages.

Windows are real API queries

Each window re-queries LFX with startDate / endDate, so these are the API's own figures, not a client-side slice. Short windows on quiet projects rest on few commits — Luigi's 100% is 456 commits over a year, not a sudden takeover.

Health score

LFX's own 0–100 composite, weighing contributor base, popularity, development practice and security posture. Hover a score to see the four parts. It is a measure of project practice, not of code quality.

Time zones

Git stores the author's local UTC offset with every commit; the GitHub API discards it, so these come from cloned history — all repositories per project, deduplicated by commit hash.

Release publishers, CI runners and service accounts commit with no time zone set and would otherwise pile up a fake UTC+00:00 workforce, so they are filtered out by author name and address. An offset is a hint about working hours, not a reliable location.
